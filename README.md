# timp-git-public

Учебный проект по дисциплине «Технологии и методы программирования».

Проект проверяет надёжность пароля в браузере

## Запуск

Откройте index.html в браузере.

Откройте файл index.html в браузере.

Автор: Артем Фамилия

## Правила проверки

Пароль должен:

- содержать не менее 8 символов;
- содержать хотя бы одну цифру;
- содержать хотя бы один специальный символ.
